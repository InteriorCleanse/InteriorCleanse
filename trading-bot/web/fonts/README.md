# Fonts

Served by the app itself from `/fonts/*.woff2`. No font is loaded from
another site.

| File | Family | Licence |
|---|---|---|
| `instrument-sans-400.woff2`, `instrument-sans-700.woff2` | Instrument Sans (interface text) | SIL Open Font License 1.1, `InstrumentSans-OFL.txt` |
| `geist-mono-400.woff2`, `geist-mono-700.woff2` | Geist Mono (numbers, prices, code) | SIL Open Font License 1.1, `GeistMono-OFL.txt` |

They are converted from the TTFs in `.claude/skills/canvas-design/canvas-fonts/`
(fontTools, WOFF2, subset to Latin, Latin-1, punctuation, arrows and maths
symbols). The fonts were subset but not otherwise modified.
