# Name: Picked

**Recommendation:** Picked, written as the lowercase wordmark `picked`.
Line: *Real fruit. Real protein.* Long form: *Tastes like it was just picked.*

## Why this name

- It says fresh fruit without saying "fruit", so it can grow past one flavor.
- It is a past participle people already use about produce, which makes the
  promise feel literal rather than invented.
- One syllable, six letters, easy to say in a store and to spell in a search bar.
- The dot of the "i" becomes a leaf, so the logo carries the idea by itself.

## Owner actions before spending on packaging

1. Search "PICKED" yourself at tmsearch.uspto.gov in classes 5, 29, 30, and 32.
2. Pay a trademark attorney for a clearance opinion. A one-word mark in food
   is the place a cheap search misses things.
3. If clear, file in class 5 (dietary supplements) and class 32 (powders for
   making beverages). Amazon Brand Registry accepts a pending application.
4. Register pickedprotein.com and drinkpicked.com, then the @pickedprotein
   handle on Instagram and TikTok. Fallback handle: @drinkpicked.
5. If "Picked" fails clearance, fall back to Bushel; the brand system works
   unchanged except the wordmark.
