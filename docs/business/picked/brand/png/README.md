# Picked PNG exports

Raster copies of the vector artwork in `brand/`, for tools that don't take SVG.

| File | Use |
| --- | --- |
| `picked-mark-512.png`, `picked-mark-1024.png` | Profile picture on every platform |
| `picked-wordmark-*.png` | The wordmark on cream, in three widths |
| `picked-wordmark-reverse-*.png` | The wordmark on crown green, in three widths |
| `pouch-strawberry-1200.png`, `pouch-mango-1200.png`, `pouch-raspberry-lemon-1200.png` | Pouch fronts, 1200 × 1720, transparent corners |
| `pouch-back-strawberry-1200.png` | Pouch back panel, 1200 × 1720 |

The pouches are concept art. Label them as concept art wherever they appear
until a real pouch is photographed.

**Figma:** the brand file's "07 Packaging" board has four empty slots named
`Pouch / Strawberry`, `Pouch / Mango`, `Pouch / Raspberry Lemon`, and
`Back / Strawberry`. Select a slot, then drag the matching PNG onto it (or use
Fill, Image, Fit). The upload could not be done from the build environment.

To re-export after changing the artwork, render the SVG at 2× (600 × 860
viewport) with any headless browser.
