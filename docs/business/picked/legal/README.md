# Picked legal drafts

**Every file here is a working draft written to save lawyer time, not legal
advice.** Have a business lawyer licensed in your state review each one
before you use it. Brackets mark facts only you can supply.

| File | Use it for | Needed by |
| --- | --- | --- |
| `terms-of-service.md` | The store's terms of sale and site use | First sale |
| `privacy-policy.md` | What the store collects and why | First email signup |
| `shipping-and-returns.md` | Shipping times, damaged orders, refunds | First sale |
| `subscription-terms.md` | Auto-renewing orders and how to cancel | First subscription |
| `consumer-health-data-policy.md` | Washington's My Health My Data Act and similar laws | First sale |
| `wholesale-terms.md` | Terms for stores buying direct | First store account |
| `mutual-nda.md` | Talking formulas with a manufacturer | First manufacturer call |
| `supply-agreement-term-sheet.md` | What the manufacturing contract must cover | Before the first deposit |
| `creator-agreement.md` | Gifted or paid creator posts | First creator send |
| `recall-plan.md` | Pulling a lot from market | Before first shipment |
| `adverse-event-sop.md` | Handling a customer who reports a reaction | Before first shipment |

See `../LEGAL.md` for the full compliance checklist and the sources behind it.
