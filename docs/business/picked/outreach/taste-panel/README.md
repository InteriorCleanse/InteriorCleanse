# The blind taste panel

Picked ships a flavor only if people pick it, blind, as the one that tastes
most like real fruit. This kit runs that test with about 30 people in one
afternoon. Print `scoresheet.pdf`, one per person.

## The ship rule

Ship the flavor only if **all three** are true:

1. **Real fruit:** Picked's average "tastes like real [fruit]" score is the
   highest of the three samples.
2. **Liking:** Picked's average overall liking is **7.0 or higher** out of 9.
3. **Preference:** at least **half** of tasters choose Picked as the one they'd
   drink again.

If it misses, send the manufacturer the comments on aftertaste, sweetness,
and texture, and run another round. Don't lower the bar.

## What you need

| Item | Amount |
| --- | --- |
| Picked sample (from the manufacturer) | enough for 30 × 2 oz plus spares |
| Two comparison products: clear whey in the same fruit flavor from two well-known brands | one tub each |
| Clear 2 oz tasting cups with lids | 100 |
| Shaker bottles | 3, one per product |
| Cold water, ice, a measuring scoop and a kitchen scale | |
| Plain crackers and still water for between samples | |
| Pens, printed scoresheets, sticky labels for codes | 30+ |
| An opaque cooler or tray so nobody sees which product is which | |

Budget about $150 including the comparison products.

## Who tastes

- 30 adults, 18 or over, from the waitlist and local run clubs or gyms.
  Ask on Instagram and in a waitlist email.
- **Screen for allergies:** every sample contains milk. Anyone with a milk
  allergy doesn't taste. Ask before they sit down, and again on the sheet.
- Mix of people: some who drink protein most days, some who rarely do.
- Not your family, not the manufacturer's team.
- Thank them with a free pouch from the first batch. Tell them it's a thank
  you, not payment for a good score. If they later post or review, they say
  it was gifted.
- Collect only a first name and whether they want the thank-you pouch. Keep
  any contact details on the waitlist, not on the sheet.

## How to run it

1. **Make up each product by its own label directions,** in cold water,
   then chill all three to the same temperature. Same cup, same amount
   (2 oz), same temperature.
2. **Code the samples.** Give each product a random three-digit code (for
   example 418, 752, 269). Only one person, who doesn't hand out samples,
   knows which is which. Write the key down and seal it.
3. **Rotate the order.** There are six possible orders of three samples. Give
   each taster the next order on the list below, so every product is tasted
   first, second, and third equally often.

   | Taster | Order |
   | --- | --- |
   | 1, 7, 13, 19, 25 | A B C |
   | 2, 8, 14, 20, 26 | A C B |
   | 3, 9, 15, 21, 27 | B A C |
   | 4, 10, 16, 22, 28 | B C A |
   | 5, 11, 17, 23, 29 | C A B |
   | 6, 12, 18, 24, 30 | C B A |

4. **Say the same thing to everyone:** "Three fruit protein drinks. Taste
   each, have a cracker and water between, and answer honestly. There are
   no right answers." Don't say which one is yours. Don't watch their face.
5. **No talking** between tasters until everyone's done.
6. **Score it the same day.** Enter each sheet in a spreadsheet: one row per
   taster, one column per question per sample. Average each score, count
   the "drink again" choices, then open the sealed key.

## What to write down afterwards

- The three averages and the preference count, for each product.
- The most common words for Picked in "what would you change".
- The ship decision and why.
- Keep the sheets. They're the evidence behind any taste claim. You may say
  "chosen in a blind taste test" only with the date, the number of people,
  and what it was compared against, and only if the result supports it.
  Never name the comparison brands in an ad without a lawyer's review.
