Questions, answered.

When can I buy it?

We plan to ship the first Strawberry batch in early 2027. The waitlist hears first and gets founding pricing.

Is it a clear protein?

It's designed to mix like a clear whey: light, juice-like, not milky. It's a little cloudy, because real fruit is.

How is it sweetened?

With the fruit, plus monk fruit and/or stevia. No sucralose, no acesulfame potassium, no aspartame.

What's in it besides fruit?

Whey protein isolate, so it contains milk. The full ingredient list goes up here when the recipe is final.

How do you test it?

Every batch will be lab tested for heavy metals, and a QR code on the pack will open that batch's results. First results post when the first batch is made.

How much does it cost?

The plan is $54.99 for a 20-serving pouch, or 15% less on subscription. Founding members get 20% off their first pouch. Founding pricing runs for a set window once pre-orders open, and the waitlist gets the date first.
