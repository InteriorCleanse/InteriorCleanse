What's Lot 001?

The first batch of Picked Strawberry. It's a small run, so the line gets first go. Its lab results post in the Lot Book before a single pouch ships.

Is it a clear protein?

It's designed to mix like a clear whey: light and juice-like, not milky. It's a little cloudy, because real fruit is.

How is it sweetened?

With the fruit, plus monk fruit and/or stevia. No sucralose, no acesulfame potassium, no aspartame.

What's in it besides fruit?

Whey protein isolate, so it contains milk. The full ingredient list goes up here when the recipe is final.
