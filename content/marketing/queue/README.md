# Approval queue

Drafts from `/marketing-team` land here, one file per item, named
`<YYYY-MM-DD>-<department>-<n>.md`, each marked `awaiting approval`.

The owner reads each one and either posts or sends it (then changes the status
to `approved` and adds the live link), edits it, or deletes the file. Nothing
in this folder is ever published automatically. See `docs/MARKETING_TEAM.md`.
